치이카와 데스크톱 — 개인용 Mac 프로토타입

현재 버전: 0.9.2 — 하치와레 한 명의 동작을 먼저 개발합니다.
다른 캐릭터의 그림과 기존 발신자 설정은 보존하되, 화면과 시연에는 하치와레만 표시합니다.
하치와레는 승인된 캐릭터 시트를 바탕으로 좌우 24프레임, 다른 방향 12프레임의 투명 PNG를 사용합니다.
상하좌우는 사용자가 지정한 시트, 아래쪽 대각선은 고정된 몸과 같은 크기의 두 발을
반 주기 간격으로 움직이는 승인 시트를 사용합니다. 대각선 발 크기는 원화 비율을 유지합니다.
위쪽 대각선은 사용자의 선택에 따라 기존 시트와 재생 동작을 그대로 유지합니다.
좌우 걷기는 사용자가 승인한 T포즈 기반 24프레임 시트를 시간 순서대로 재생합니다.
한 발당 12프레임이며, 착지·내려감·교차·올라감이 양발에서 같은 궤적을 반 주기 차이로 반복합니다.
원본 시트의 발 크기와 몸 높낮이를 그대로 유지하고, 오른쪽도 완성된 같은 프레임을 반전해 사용합니다.
몸과 발의 연결부에서 겹친 내부 선만 정리했습니다. 발 궤적·각도·타이밍·이동 속도는 유지합니다.
팔도 어깨 쪽 닫힌 선을 열어 몸에 이어지게 했으며, 팔의 회전 중심·흔들림과 손끝 위치는 유지합니다.
착용한 소품도 해당 프레임의 몸 높이에 맞춰 움직이며, 소품 위의 별도 흰 손 원은 제거했습니다.
위로 걸을 때는 뒷모습, 아래로 걸을 때는 정면, 좌우로 걸을 때는 측면을 사용합니다.
새 레퍼런스로 웃기·볼에 손 대기·놀라기·줍기·소품 동작을 추가했습니다.
마우스를 올리면 짧게 인사한 뒤 웃고, 알림을 받으면 놀라는 표정을 보여 줍니다.
‘표정과 소품 동작’을 끄면 기존 인사 프레임을 사용합니다.

실행
  build/ChiikawaCompanion.app을 엽니다.
  창을 닫아도 캐릭터는 남습니다. 메뉴 막대의 발바닥에서 설정과 종료를 할 수 있습니다.

사용법
  • 캐릭터 위에 마우스를 올리면 반응합니다. 클릭하면 음성 대사 4개와 사용자가 지정한
    명대사 10개를 합친 총 14개 중 하나를 같은 확률로 무작위 선택합니다.
    직전 대사는 연속으로 반복하지 않습니다. 녹음이 있는 4개만 해당 음성과 같은 말풍선을 보여 줍니다.
    “초밥이다!”, “엉망진창으로 뒤섞였어.”, “맛있다!”, “그래서 말이야.”는 손정민 성우의 공개 녹음입니다.
    명대사 10개는 글로 표시합니다. 다시 클릭하면 기존 음성을 끊고 새 대사를 보여 줍니다.
    설정의 ‘하치와레의 목소리’에서 클릭 목소리, 음량, 미리 듣기, 멈추기를 조절할 수 있습니다.
    음소거해도 14개 모두 말풍선으로 나옵니다. 카톡 수신 TTS와 클릭 목소리는 별도 설정입니다.
    앱에 포함된 음성은 Mac에서 재생되며 인터넷 연결 없이 동작합니다. 음성 합성 기능은 추가하지 않았습니다.
  • 카메라·기타·파란 사스마타가 바탕화면에 놓입니다.
    하치와레가 가까이 가면 주워 착용하고, 8방향으로 들고 걸어 다닙니다.
    사진 찍기·기타 연주·준비 자세를 잠깐 보여 준 뒤 산책을 이어 갑니다.
    카메라 동작은 그림 효과이며 실제 카메라·화면 촬영을 하지 않습니다. 기타 소리는 재생하지 않습니다.
    한 번에 한 소품을 착용하며, 새 소품을 주우면 이전 것은 바탕화면에 내려놓습니다.
    설정에서 소품별 표시, ‘스스로 주워 입기’, ‘표정과 소품 동작’을 켜고 끌 수 있습니다.
    바닥 소품을 클릭하거나 ‘주우러 가기’로 골라 부르면 직접 걸어와 줍습니다.
    소품 드래그, ‘다시 흩어 놓기’, ‘내려놓기’도 지원합니다.
    캐릭터와 바닥 소품의 좌표는 독립적입니다. 캐릭터 드래그나 ‘하치와레 부르기’로
    소품 위치가 바뀌지 않습니다. 직접 소품을 옮기거나, 줍고 내려놓거나,
    ‘다시 흩어 놓기’를 누를 때에만 해당 소품 위치가 바뀝니다.
  • 동굴 집은 화면 중앙 하단, Dock 위에 고정되며 일반 앱 창 뒤에 표시합니다.
    집을 클릭하거나 설정의 ‘집에 가서 자기’를 누르면 걸어갑니다.
    직접 캐릭터를 입구로 끌어다 놓아도 잠듭니다. 입구에 도착하기 전에는 잠들지 않습니다.
    들고 있던 소품만 집 옆에 내려놓고, 이불을 덮은 수면 그림과 호흡·z 효과를 보여 줍니다.
    잠든 집을 클릭하거나 ‘깨우기’를 누르면 일어납니다. 20초 후에도 스스로 일어납니다.
    카톡 알림이나 소품 요청도 수면을 중단합니다. 알림 감지를 꺼 둔 상태에서는 실제 수신을 감지하지 않습니다.
    ‘가끔 집에서 쉬기’를 켜면 산책 중 약 90초 간격으로 집에 돌아갑니다.
    캐릭터를 드래그하면 귀가를 취소합니다. 집·바닥 소품·캐릭터는 좌표를 따로 유지합니다.
    ‘집 표시’를 끄면 집이 숨겨지고, 안에 있던 캐릭터는 입구로 나옵니다.
    가방 옵션은 제거했습니다. 이전 생성 이미지들은 Source 기록에 보존합니다.
  • 드래그해서 위치를 옮깁니다. ‘하치와레 부르기’로 처음 위치에 다시 부릅니다.
  • 캐릭터 카드에 카톡 알림에 표시되는 발신자 이름을 입력합니다.
    이름이 정확히 일치하는 새 알림의 미리보기 내용을 캐릭터 말풍선에 잠깐 표시합니다.
    Mac과 카카오톡에서 알림 내용 미리보기를 켜야 합니다. 숨겨진 내용은 읽을 수 없습니다.
    긴 내용은 최대 500자·8줄까지 표시하며 생략될 수 있습니다. 말풍선은 6~12초 후 사라집니다.
  • 캐릭터와 말풍선은 바탕화면 아이콘 위, 일반 앱 창 아래에 표시합니다.
    Chrome 등의 창이 가리는 영역에서는 그 창 뒤에 가려집니다.
  • 하치와레는 화면 전체에서 상하좌우로 목적지를 바꾸며 걷습니다.
    마우스를 올리거나 드래그하거나 말풍선이 표시되는 동안에는 잠시 멈춥니다.
    호버 반응은 마우스를 올린 동안만 유지하며, 떼면 다음 갱신에서 걷기를 재개합니다.
    이동과 호버 판정은 초당 60회 갱신합니다. 걷기를 끈 상태와 알림 말풍선은 유지합니다.
    좌우는 24프레임, 다른 방향은 12프레임이며, 실제 이동한 거리 62.7pt마다 한 주기를 재생합니다.
    정상 속도에서는 한 주기가 약 1.36초이고, 감속·정지에 따라 발걸음도 느려지거나 멈춥니다.
    대각선은 앞·뒤 ¾뷰를 사용하며, 옆면과 대각선은 좌우 반전해 총 8방향을 표현합니다.
  • ‘알림 시연’은 실제 카카오톡과 무관한 테스트입니다. 말풍선에 [시연]이 표시됩니다.
  • 목소리 알림은 기본으로 꺼져 있습니다. 설정에서 켤 수 있습니다.
    음성은 발신자의 수신 사실만 알려주며 메시지 본문은 읽지 않습니다.
  • 같은 이름을 둘 이상에게 지정하면 그 이름의 알림은 처리하지 않습니다.

실제 카카오톡 알림 — 실험 기능 / 실제 수신 검증 전
  카카오톡의 메시지 수신 API를 사용하지 않습니다.
  macOS Notification Center가 접근성 정보로 내보내는 앱 이름·발신자·알림 본문을 읽습니다.
  알림 감지를 켜고, 필요할 경우 ‘손쉬운 사용 설정 열기’에서 사용자가 직접 권한을
  허용해야 합니다. 앱 실행만으로 권한을 요청하거나 변경하지 않습니다.
  권한 목록에 없으면 + 버튼으로 이 앱을 직접 추가합니다.

  macOS 및 카카오톡 버전, 알림 미리보기 설정, 방해 금지, 알림 표시 형식에 따라
  감지가 안 될 수 있습니다. 우선 1:1 채팅으로 실제 수신 테스트를 해야 합니다.
  단체방 발신자 구분, 동명이인 구분, 알림이 생성되지 않는 상황은 지원을 보장하지 않습니다.
  앱 재빌드 뒤에는 macOS에서 손쉬운 사용 권한을 다시 설정해야 할 수도 있습니다.

데이터
  네트워크 요청, 메시지 전송, 자동 답장, 원본 카톡 데이터베이스 접근은 없습니다.
  발신자 매핑과 산책·알림 음성·클릭 목소리·음량·소품·표정·집 설정을 이 앱의 UserDefaults에 로컬 저장합니다.
  소품 위치와 착용 상태는 실행 중에만 유지됩니다.
  메시지 내용은 말풍선 표시를 위해 메모리에서만 처리하며 파일·설정·로그로 기록하거나
  외부로 보내지 않습니다. 중복 방지용 해시는 메모리에만 둡니다. 대화 이력은 제공하지 않습니다.
  실행 중인 감지 여부는 저장하지 않으며, 앱을 다시 열면 알림 감지는 꺼져 있습니다.

소스 빌드 (macOS 13+, Xcode Command Line Tools)
  bash scripts/build.sh
  .build/release/ChiikawaCompanion --self-test

검증 범위
  --self-test는 발신자 매칭, 파서 예시, 중복 제거, 화면 경계, 2차원 이동,
  창 레벨 순서, 걷기 순서, 소품 줍기·교체·내려놓기·표시 해제,
  집 위치·입구 도착·입장·수면·기상·소품 좌표 독립, 녹음 파일·말풍선 일치,
  재생 교체·음소거·알림 우선순위·음량·기존 설정 보존을 검증합니다.
  예시 데이터로 성공해도 실제 카카오톡 연동이 검증된 것은 아닙니다.

캐릭터
  하치와레는 사용자 제공 이미지로 만든 캐릭터 시트 기반의 팬메이드 PNG 애니메이션입니다.
  치이카와·우사기·모몽가·쿠리만쥬는 기존 팬메이드 벡터 초안입니다.
  실행 리소스는 사용자 레퍼런스에서 생성한 팬메이드 그림과 자체 소품 도형입니다.
  Source에는 사용자 제공 레퍼런스·생성 원본·중간 시트·검토 이미지도 보관합니다.
  공식 웹 자료는 소품 확인에 참고했으며 출처는 Source/ExpressionsAndItems-v7/references.json에 기록합니다.
  성우 공개 음성 샘플의 출처와 편집 구간은 Source/VoiceClips-v13/provenance.json과 catalog.json에 기록합니다.
  개인 사용을 위한 프로젝트이며, X 게시 등 공개 이용에 대한 권리 허락을 뜻하지 않습니다.
