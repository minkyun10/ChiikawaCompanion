치이카와 데스크톱 — 개인용 Mac 프로토타입

현재 버전: 0.17.2 — 하치와레와 치이카와가 함께 지냅니다.
치이카와는 8방향 모두 양발 전체 24프레임의 투명 PNG를 사용합니다.
캐릭터별 위치·걷기 위상·말풍선·장착 소품·줍기 목적지는 독립적입니다.
설정에서 각 친구의 표시·산책을 따로 켜고 끄거나 한 명만 부를 수 있습니다.
전체 표시·전체 산책 스위치는 두 친구에게 함께 적용합니다.
치이카와를 클릭하거나 드래그해도 하치와레의 음성·공부·수면은 중단되지 않습니다.
치이카와는 웃음·울음·놀람·용기·수줍은 기쁨의 표정과 이주은 성우의 실제 녹음 4개를 사용합니다.
말풍선의 …!, …♡ 등은 앱의 감정 표시이며 녹음의 문장 전사가 아닙니다.
호버 중에는 웃고, 마우스를 떼면 다음 갱신에서 걷습니다. 치이카와 클릭 말풍선은 약 2~3초 유지합니다.
치이카와 전용 곰 포셰트·분홍 사스마타·집 열쇠·갈색 인형은 바탕화면에서 줍거나 직접 건넵니다.
소품 클릭 방문·몸 접촉 줍기·드래그 드롭·교체·내려놓기·개별 표시·자동 줍기를 지원합니다.
분홍 소품은 치이카와에게, 카메라·기타·파란 사스마타는 하치와레에게 연결됩니다.
분홍 사스마타를 든 치이카와는 마우스를 올린 동안 12프레임 공격을 1.2초 주기로 반복합니다.
사용자 레퍼런스 왼쪽 치이카와의 힘준 눈썹·미간 주름·뜬 눈·분홍 혀가 보이는 입과
양손으로 무기를 잡은 자세를 반영했습니다. 마우스를 떼면 다음 60Hz 갱신에서 기존 산책으로 돌아갑니다.
클릭 대사·드래그는 공격보다 우선하며, 걷기를 꺼 두었다면 공격 후에도 서 있습니다.
분홍 포셰트나 빈손일 때에는 평소 웃는 호버로 반응합니다. 무기 표시 해제도 공격을 즉시 해제합니다.
공격 그림에 무기가 포함되어 별도 소품을 겹쳐 그리지 않습니다. '표정과 소품 동작'을 끄면 공격도 꺼집니다.
두 캐릭터의 공격 그림은 평소 걷는 몸의 너비·중심·발 위치에 맞춰 표시합니다.
긴 무기 때문에 캐릭터를 줄이지 않으며, 그림의 표시 공간만 넓혀 무기가 잘리지 않게 합니다.
캐릭터 좌표·이동·마우스 반응 영역과 12프레임 공격 동작·속도는 유지합니다.
집은 공용 한 채이며 기본 디자인은 하치와레 집입니다. 설정의 ‘함께 쉬는 집 → 집 디자인’에서 선택합니다.
치이카와 디자인은 이전의 크림색·분홍색 둥근 집을 사용하며 원본 비율을 유지합니다.
모든 캐릭터가 선택한 공용 집에서 함께 잘 수 있습니다. 캐릭터가 늘어나도 집은 추가하지 않습니다.
치이카와는 식사·인형 안기·잠옷 입기를 각각 12프레임, 수면·기상을 합쳐 16프레임으로 보여 줍니다.
눈 깜박임 6프레임은 기존 정면 걷기의 눈 부분에만 합성하고 표정은 0.1초 동안 전환합니다.
열쇠 귀가·분홍 책상 공부·한국어 클릭 음성도 지원합니다. 치이카와 토하기는 추가하지 않습니다.
기존 8방향 걷기·공격 리소스와 하치와레의 그림·녹음은 그대로 유지합니다.
아래의 명대사·녹음·생활 동작 설명은 하치와레에 해당합니다. 집은 두 캐릭터가 공유합니다.
하치와레는 승인된 캐릭터 시트를 바탕으로 좌우 24프레임, 다른 방향 12프레임의 투명 PNG를 사용합니다.
상하좌우는 사용자가 지정한 시트, 아래쪽 대각선은 고정된 몸과 같은 크기의 두 발을
반 주기 간격으로 움직이는 승인 시트를 사용합니다. 대각선 발 크기는 원화 비율을 유지합니다.
위쪽 대각선은 사용자의 선택에 따라 기존 시트와 재생 동작을 그대로 유지합니다.
좌우 걷기는 사용자가 승인한 T포즈 기반 24프레임 시트를 시간 순서대로 재생합니다.
한 발당 12프레임이며, 착지·내려감·교차·올라감이 양발에서 같은 궤적을 반 주기 차이로 반복합니다.
원본 시트의 발 크기와 몸 높낮이를 그대로 유지하고, 오른쪽도 완성된 같은 프레임을 반전해 사용합니다.
몸과 발의 연결부에서 겹친 내부 선만 정리했습니다. 발 궤적·각도·타이밍·이동 속도는 유지합니다.
팔도 어깨 쪽 닫힌 선을 열어 몸에 이어지게 했으며, 팔의 회전 중심·흔들림과 손끝 위치는 유지합니다.
착용한 소품도 해당 프레임의 몸 높이에 맞춰 움직이며, 소품 위의 별도 흰 손 원은 제거했습니다.
위로 걸을 때는 뒷모습, 아래로 걸을 때는 정면, 좌우로 걸을 때는 측면을 사용합니다.
새 레퍼런스로 웃기·볼에 손 대기·놀라기·줍기·소품 동작을 추가했습니다.
마우스를 올리면 짧게 인사한 뒤 웃고, 클릭하면 목소리나 명대사를 들려줍니다.
파란 사스마타를 들었을 때는 호버하면 힘준 표정으로 무기를 앞으로 내지르는 12프레임 공격을 보여 줍니다.
레퍼런스의 뜬 눈·안쪽으로 기울인 눈썹·코 주름·분홍 혀가 보이는 입을 반영했습니다.
공격은 마우스를 올린 동안만 1.2초 주기로 순서대로 반복하며, 떼면 다음 갱신에서 기존 산책으로 돌아갑니다.
‘표정과 소품 동작’을 끄면 기존 인사 프레임을 사용합니다.

실행
  build/ChiikawaCompanion.app을 엽니다.
  창을 닫아도 캐릭터는 남습니다. 메뉴 막대의 발바닥에서 설정과 종료를 할 수 있습니다.

사용법
  • 치이카와도 화면 중앙 하단의 공용 집을 이용합니다. 집 디자인과 입장할 수 있는 캐릭터는 무관합니다.
    설정의 치이카와 ‘집에 가서 자기’를 누르면 바닥의 열쇠를 챙겨 공용 집으로 걸어갑니다.
    열쇠를 들고 있거나 표시를 꺼 두었으면 바로 집으로 갑니다. 귀가 중 열쇠를 건네도 이어서 귀가합니다.
    입구에 도착하면 들고 있던 소품만 집 옆에 내려놓고 잠옷을 입은 뒤 이불 속에서 쉽니다.
    20초 후 스스로 일어나며 집을 다시 클릭하거나 ‘깨우기’로도 일어납니다.
    치이카와를 숨기면 해당 수면 상태만 해제합니다. 공용 집은 그대로 남고 소품 좌표도 유지합니다.
    직접 입구로 끌어다 놓아도 잠들며, 드래그는 진행 중인 귀가를 취소합니다.
    분홍 책상을 클릭하면 걸어가 공부합니다. 가까이 지나가거나 데려다 놓아도 12프레임 공부를 9초간 합니다.
    책상은 따로 드래그해 옮깁니다. 자동 공부는 34pt 진입, 84pt 이탈, 30초 재반응 대기를 사용합니다.
    분홍 잠옷은 옷을 끌어올리고 팔을 넣고 후드를 쓰는 12프레임 뒤 완성 자세를 유지합니다.
    인형 안기는 들어 올리기 → 가슴으로 당기기 → 꼭 안기 → 살짝 풀기의 12프레임입니다.
    잠옷과 인형 동작은 각각 5초 후 산책으로 돌아갑니다.
    인형을 주워도 곧바로 안아 줍니다. 설정·우클릭·메뉴 막대의 ‘치이카와의 하루’에서 고릅니다.
    치이카와 전용 밥그릇은 별도 화면 좌표를 가지고 클릭 방문·드래그 이동·가까이 가기 반응을 지원합니다.
    34pt 안에 들어오면 초록 그릇과 젓가락으로 밥 먹는 12프레임을 1.8초 주기로 총 6초 보여 줍니다.
    그동안 그림에 이미 있는 밥그릇만 숨기고 끝나면 같은 위치에 복원합니다. 다른 소품과 장착 상태는 유지합니다.
    자동 행동을 꺼도 밥그릇을 클릭하거나 ‘밥그릇으로 가기’를 누르면 걸어가 먹습니다.
    84pt 밖으로 나갔다 돌아와야 다시 자동 반응하며 30초 간격을 둡니다. 밥그릇을 숨기면 해당 방문·식사를 취소합니다.
    수면 입장에서는 하품 → 눕기 → 이불 덮기 → 눈 감기 8프레임, 기상은 눈뜨기 → 이불 걷기 → 일어나 기지개 8프레임을 보여 줍니다.
    치이카와는 기상 0.96초 동안 집 안에 표시되고 끝난 다음 산책합니다. 다른 동작을 고르거나 해당 캐릭터를 숨기면 기상 전환을 취소합니다.
    클릭하면 이주은 성우의 공개 치이카와 연기 샘플에서 자른 짧은 반응 4개 중 하나가 나옵니다.
    클릭 음성은 직전 녹음을 연속으로 반복하지 않습니다.
    소리는 캐릭터를 클릭하거나 ‘목소리 들어보기’를 직접 누를 때만 나옵니다.
    공부·식사·인형 안기·잠옷 입기·호버 공격·수면·기상 등 모든 행동은 자동으로 소리를 내지 않습니다.
    클릭 음성에 대기 시간은 없으며 다시 클릭하면 즉시 다음 반응으로 바뀝니다.
    하치와레와 음성 플레이어·중단·켜기 설정을 따로 유지합니다.
    두 친구의 음량 슬라이더는 공통입니다. 인터넷 없이 로컬 재생합니다. 합성·복제 음성은 없습니다.
    감정별 파일 이름과 말풍선은 제작상 배치이며, 실제 대사 문장 전사나 공식 장면 이름이 아닙니다.
    원본에 겹쳐 있는 배경음은 별도 분리하지 않았습니다. ‘치이카와의 목소리 → 클릭 목소리’에서 켜고 끌 수 있습니다.
  • 하치와레 위에 마우스를 올리면 반응합니다. 클릭하면 음성 대사 4개와 사용자가 지정한
    명대사 10개를 합친 총 14개 중 하나를 같은 확률로 무작위 선택합니다.
    직전 대사는 연속으로 반복하지 않습니다. 녹음이 있는 4개만 해당 음성과 같은 말풍선을 보여 줍니다.
    “초밥이다!”, “엉망진창으로 뒤섞였어.”, “맛있다!”, “그래서 말이야.”는 손정민 성우의 공개 녹음입니다.
    명대사 10개는 글로 표시합니다. 다시 클릭하면 기존 음성을 끊고 새 대사를 보여 줍니다.
    설정의 ‘하치와레의 목소리’에서 클릭 목소리, 음량, 미리 듣기, 멈추기를 조절할 수 있습니다.
    음소거해도 14개 모두 말풍선으로 나옵니다.
    앱에 포함된 음성은 Mac에서 재생되며 인터넷 연결 없이 동작합니다. 음성 합성 기능은 추가하지 않았습니다.
  • 바탕화면의 책상 근처에서는 공부하고, 털뭉치 근처에서는 토하고, 밥 근처에서는 밥을 먹습니다.
    소품을 클릭하거나 설정의 ‘책상으로 가기’ 등으로 부르면 그곳까지 걸어갑니다.
    캐릭터를 소품 가까이에 끌어다 놓아도 해당 동작을 합니다.
    소품은 드래그로 따로 옮길 수 있으며 캐릭터를 옮겨도 좌표가 바뀌지 않습니다.
    ‘하치와레의 하루’에서 소품별 표시와 ‘가까이 가면 행동하기’를 켜고 끕니다.
    발 위치가 34pt 안에 들면 반응합니다. 한 번 행동한 뒤에는 84pt 밖으로 나갔다
    돌아와야 다시 반응하며, 공부·식사는 30초, 토하기는 45초 간격을 둡니다.
    소품을 직접 클릭하면 기다리지 않고 다시 걸어와 동작합니다.
    같은 자리에 서 있을 때에는 반복 발동하지 않습니다.
    설정, 캐릭터 우클릭 메뉴, 메뉴 막대에서도 일상 동작을 바로 고를 수 있습니다.
    ‘공부하기’는 혀를 빼꼼 내밀고 상자 책상에서 연필로 쓰는 12프레임 동작입니다.
    ‘밥 먹기’는 초록 밥그릇에서 젓가락으로 밥을 집어 먹는 12프레임 동작입니다.
    ‘토하기’는 사용자 레퍼런스의 만화적 연출이며, 한 번의 동작만 재생합니다.
    공부는 약 9초, 식사는 약 6초, 토하기는 약 2.4초 후 이전 산책 상태로 돌아갑니다.
    직접 고른 일상 동작은 호버 중에도 이어지며 클릭·드래그·‘동작 멈추기’로 중단합니다.
    잠든 상태에서 고르면 집에서 일어나 동작을 보여 줍니다. 걷기를 꺼 두었다면 끝난 뒤 서 있습니다.
    손이 바쁜 동안 착용 소품의 그림만 잠시 가립니다. 바닥 소품 좌표와 착용 상태는 유지합니다.
    공부·식사 그림에 책상·밥그릇이 포함되어 있어 동작 중에는 해당 바닥 소품만 숨깁니다.
    동작이 끝나면 정확히 같은 위치에 다시 표시합니다.
  • 카메라·기타·파란 사스마타가 바탕화면에 놓입니다.
    하치와레가 가까이 가면 주워 착용하고, 8방향으로 들고 걸어 다닙니다.
    자동 줍기는 발밑 한 점 대신 둥근 몸 영역과 64pt 소품 그림이 닿는지 검사합니다.
    이동 직전과 직후 모두 검사하므로, 다른 곳으로 걷는 중 닿은 소품도 바로 줍습니다.
    자동 교체는 최소 3초 간격이고, 내려놓은 같은 소품은 12초 동안 다시 줍지 않습니다.
    24초 대기는 다음 소품을 스스로 찾아 걸어가는 데만 적용하며, 지나가다 닿는 줍기를 막지 않습니다.
    소품을 직접 클릭해 고른 목적지, 집·생활 소품 방문, 클릭 대사·호버·드래그·일상 동작은 우선합니다.
    사진 찍기·기타 연주·준비 자세를 잠깐 보여 준 뒤 산책을 이어 갑니다.
    카메라 동작은 그림 효과이며 실제 카메라·화면 촬영을 하지 않습니다. 기타 소리는 재생하지 않습니다.
    한 번에 한 소품을 착용하며, 새 소품을 주우면 이전 것은 바탕화면에 내려놓습니다.
    설정에서 소품별 표시, ‘스스로 주워 입기’, ‘표정과 소품 동작’을 켜고 끌 수 있습니다.
    바닥 소품을 클릭하거나 ‘주우러 가기’로 골라 부르면 직접 걸어와 줍습니다.
    카메라·기타·사스마타를 하치와레의 얼굴이나 몸 위로 드래그해 놓으면 즉시 듭니다.
    걷기나 자동 줍기를 꺼 두어도 직접 건넬 수 있습니다. 이전 소품만 옆에 내려놓고
    다른 바닥 소품은 그대로 둡니다. 바닥에 드롭하면 해당 소품의 자리만 바뀝니다.
    소품 드래그, ‘다시 흩어 놓기’, ‘내려놓기’도 지원합니다.
    캐릭터와 바닥 소품의 좌표는 독립적입니다. 캐릭터 드래그나 ‘하치와레 부르기’로
    소품 위치가 바뀌지 않습니다. 직접 소품을 옮기거나, 줍고 내려놓거나,
    ‘다시 흩어 놓기’를 누를 때에만 해당 소품 위치가 바뀝니다.
  • 집은 화면에 공용 한 채만 표시합니다. 기본값은 하치와레 집이며,
    설정의 ‘함께 쉬는 집 → 집 디자인’에서 하치와레 / 치이카와를 선택합니다.
    위치는 기존 하치와레 집과 같은 화면 중앙 하단, Dock 위로 고정됩니다.
    모든 디자인은 같은 360 × 214pt 표시 영역과 입구·수면 기능을 공유합니다.
    하치와레는 동굴, 치이카와는 이전의 크림색·분홍색 둥근 집을 원본 비율로 표시합니다.
    캐릭터별 집 창이나 별도 위치는 만들지 않습니다.
    빈 집을 클릭하면 화면에 보이는 친구들이 함께 걸어갑니다.
    캐릭터별 ‘집에 가서 자기’를 누르거나 캐릭터를 입구에 데려다 놓아도 잠듭니다.
    입구에 도착하면 들고 있던 소품만 내려놓고 이불을 덮어 자며 호흡·z 효과를 보여 줍니다.

    자는 집을 클릭하면 안의 친구들을 깨웁니다. 캐릭터별 ‘깨우기’도 가능하며 20초 후 스스로 일어납니다.
    디자인을 바꾸어도 집 위치·크기·입구와 잠든 친구·수면 시간·바닥 소품 좌표는 유지합니다.
    ‘가끔 쉬기’를 켜면 해당 친구가 약 90초 간격으로 돌아옵니다. 드래그하면 해당 귀가만 취소합니다.
    한 친구를 숨겨도 공용 집과 다른 친구의 잠은 유지합니다. 전체 친구 숨김은 집도 함께 숨깁니다.
    이후 캐릭터와 디자인을 추가할 때도 DesktopHome 한 개와 HomeGeometry를 공유하며,
    디자인은 HomeStyle, 수면 상태는 homeRoutines에 등록합니다. 캐릭터별 house panel은 만들지 않습니다.
  • 드래그해서 위치를 옮깁니다. ‘하치와레 부르기’로 처음 위치에 다시 부릅니다.
  • 캐릭터와 말풍선은 바탕화면 아이콘 위, 일반 앱 창 아래에 표시합니다.
    Chrome 등의 창이 가리는 영역에서는 그 창 뒤에 가려집니다.
  • 하치와레는 화면 전체에서 상하좌우로 목적지를 바꾸며 걷습니다.
    마우스를 올리거나 드래그하거나 말풍선이 표시되는 동안에는 잠시 멈춥니다.
    호버 반응은 마우스를 올린 동안만 유지하며, 떼면 다음 갱신에서 걷기를 재개합니다.
    이동과 호버 판정은 초당 60회 갱신합니다. 걷기를 끈 상태와 클릭 대사 말풍선은 유지합니다.
    좌우는 24프레임, 다른 방향은 12프레임이며, 실제 이동한 거리 62.7pt마다 한 주기를 재생합니다.
    정상 속도에서는 한 주기가 약 1.36초이고, 감속·정지에 따라 발걸음도 느려지거나 멈춥니다.
    대각선은 앞·뒤 ¾뷰를 사용하며, 옆면과 대각선은 좌우 반전해 총 8방향을 표현합니다.
