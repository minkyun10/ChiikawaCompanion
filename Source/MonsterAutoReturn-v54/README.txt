괴물 하치와레 자동 복귀 v54
작성: 2026-10-23
적용: 0.25.1 / build 53

사용자 선택: 일정 시간이 지나면 자동으로 돌아오기.
구체 시간은 지정하지 않아 30초를 기본값으로 적용했다.

10초 안에 하치와레 5회 클릭 → 5번째 클릭 시점부터 30초 유지 → 650ms 자동 복귀.
변신 중 클릭은 기존 음성/문구 체계로 반응하며, 복귀 시각을 연장하거나 수동 원복하지 않는다.
다른 캐릭터 클릭/하치와레 드래그는 일반 모습의 대기 클릭 묶음을 끊는다.
복귀는 말풍선·음성 재생·이동 목적지 초기화·동작 취소·소품 이동을 만들지 않는다.
걷기·공격·수면·캐릭터 숨김에서도 복귀를 갱신하고, 집 안 그림도 같은 비율로 전환한다.
앱 갱신이 늦어진 경우 다음 실제 갱신에서 650ms 전환을 시작해 그림이 순간 교체되지 않게 한다.

실행 이미지·리소스·원본·시트·미리보기 정본은 MonsterTransformation-v53과 동일하다.
이번에는 이미지를 새로 생성하지 않았다. 모든 과거 생성 시안과 원본을 Source에 유지한다.
고정 괴물 성능 benchmark의 형상 시계는 변신 1초 후로 고정한다.
실제 이동/애니메이션/측정 시계는 계속 흐르며, 앱의 실제 30초 복귀를 benchmark 전용 장면과 분리한다.

Audit에 release 빌드·targeted/full app bundle 검사·실제 UI 확인·리소스 보존 결과를 기록한다.

최종 검수
  완성 app bundle 전체 908개, 변신 전용 53개 통과.
  codesign --verify --deep --strict 통과. 새 앱 0.25.1/build 53 실행 완료.
  현재 실행 이미지 233개는 v53 보관본과 SHA-256이 모두 동일하다.
  CLI 최초 이동 검사의 첫 sub-point 변위 가정은 AppKit 좌표 반올림과 맞지 않았다.
  최종 검사는 6 tick의 연속 이동과 거리 상한을 확인하며 정상 통과했다.
  실제 UI에서 설정 창과 공용 집 표시, 캐릭터 8명 소환 복원을 확인했다.
  하치와레 아이템 스위치도 원래 on 상태로 복원했다.
  Mac은 잠금 해제됐으나 CUA가 별도 캐릭터 창을 선택하지 못해 5회 클릭 육안 확인은 수행하지 못했다.
  사용자도 현재 직접 확인하기 어렵다고 답했다. 수동 검수 통과로 기록하지 않는다.
