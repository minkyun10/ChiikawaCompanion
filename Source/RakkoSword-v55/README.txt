동작
  랏코의 아이템 스위치에 파르페 + 검과 칼집을 함께 연결했다. 메뉴 옵션은 추가하지 않았다.
  지면의 검을 클릭하면 걸어와 줍고, 랏코 몸 위로 드래그하면 자동 줍기 설정과 무관하게 즉시 장착한다.
  평소에는 칼집에 넣어 어깨 뒤에 메고 8방향으로 걷는다.
  장착 상태에서 호버하면 검을 꺼내 공격한다. 호버가 끝나면 다음 갱신에 원래 산책과 칼집으로 돌아간다.
  기존 전체 실루엣 hover mask와 고정된 공격 시계를 사용해 무기 끝에서도 공격이 끊기거나 보행과 섞이지 않는다.
  기존 아이템 교환·소유권·독립 지면 좌표·집에서 내려놓기·클릭 때만 음성 재생 규칙을 유지한다.
  다른 캐릭터의 검이나 아이템 종류는 늘리지 않는다. 허용 무기 소유자는 하치와레·치이카와·우사기·랏코다.

설정 이관
  이전 랏코 아이템이 켜져 있었다면 검을 한 번 추가한다.
  아이템이 꺼져 있으면 유지하며, 소환·걷기·음성·자동 줍기·휴식 설정을 바꾸지 않는다.
  이관 후 검을 껐다면 앱을 다시 켜도 자동으로 복구하지 않는다.

제작 방식
  기존 native rig와 vector 아이템 구조를 사용했다. 이번 작업은 imagegen 원본을 새로 만들지 않는다.
  RakkoSword.swift: 원화 제작 정본의 사본. 실행 구현은 Sources/ChiikawaCompanion/RakkoSword.swift.
  Review/: 칼집 투명 아이콘, 검 상세도, 8방향 장착, 12프레임 공격 전체 시트 및 GIF.
  Final/: 적용한 공격 전체 시트.
  Audit/: 빌드·기존 리소스 hash·설정 이관·드래그·공격·전체 회귀 검사 결과.
  앱은 준비된 공격 atlas를 한 번 decoding해 재사용한다. native 아이템 도형은 캐시된 그림 위에 합성한다.
  실행 중 Source에 PNG·로그·다운로드가 누적되지 않으며, 새 네트워크·API·권한을 추가하지 않는다.
