목적
  기존 데스크톱 캐릭터에서 활용할 수 있도록 공식 레퍼런스를 수집한 연구 자료.
  앱 구현이나 생성 원화가 아니다. 현재 실행 중인 캐릭터·코드·리소스는 변경하지 않았다.
  한국어 형태 이름은 정리용 번역이며 공식 한국어 명칭으로 검증한 것은 아니다.

수집 범위
  공식 이미지 파일 50개: 작가 공식 X 원작/일러스트 5개, 애니 공식 장면 이미지 18개, 공식 상품 이미지 27개.
  일부 상품 이미지는 비교 사진이나 예약 안내를 포함하며, 같은 안내 이미지가 중복되어 있다.
  핵심 15개는 reference-index.json에 사용 목적과 함께 선별했다.
  상품 데이터 8개, 공식 X 공개 게시물 데이터 5개, 공식 애니 에피소드 목록 2개를 함께 보관했다.
  각 원본 URL·페이지·확인 날짜·SHA-256은 sources.json에 기록했다.
  공식 X 작성자가 ngnchiikawa임을 공개 syndication 데이터에서 확인한 뒤 해당 게시물의 원본 이미지 URL을 받았다.
  X 웹 본문은 web 도구에서 403 응답을 받았으며, 수집은 공개 임베드용 데이터와 이미지 응답으로 검증했다.
  로그인·개인 계정·API key·전체 영상 다운로드를 사용하지 않았다.

  형태/색/표정은 작가 원작 일러스트 → 공식 애니 → 2D 공식 상품 → 입체 상품 순서로 판단하는 것을 제안한다.
  이것은 구현을 위한 정리 원칙이며 공식 설정문이 아니다.
  입체 상품의 봉제 비율·하드웨어·예약 문구는 캐릭터 자체의 특징에 포함하지 않는다.
  마지컬 강해진 하치와레 상품에는 보라색 코/눈 주변 색이 보이지만, 확보한 평행세계 원작 그림에는 같은 요소가 없다.
  https://chiikawamarket.jp/products/4571609413776 자료는 별도 보조 형태로 표시해 섞이지 않도록 했다.
  공식 정투영 T-pose/8방향 보행 시트는 확보하지 않았다. 측후면은 원작 부분 컷과 입체 상품을 참고할 수 있다.
  변신 후 절대 크기나 체중 등 공식 수치는 이번 자료에서 확인하지 못했다.
