하치와레 이미지 보관함

GeneratedOriginals: 이 대화에서 생성한 이미지 원본 전체. 채택하지 않은 시안도 포함합니다.
Project: 프로젝트에 저장된 캐릭터 시트, 애니메이션 GIF, 미리보기, 화면 캡처, 아이콘과 빌드 산출물의 이미지 사본입니다. 기존 경로 구조를 유지했습니다.
manifest.json: 모든 파일의 출처, 보관 경로, 크기, SHA-256 목록입니다.

앱에서 사용하는 기존 파일과 생성 원본은 그대로 두고 복사했습니다.
최신 적용: ActivitySpots-v17 — 독립적으로 옮기는 책상·털뭉치·밥과 가까이 갔을 때의 공부·토하기·식사 반응.
표정·줍기·소품 동작과 카메라·기타·사스마타를 유지합니다. 가방은 실행 옵션에서 제거했습니다.
이전 가방 이미지를 포함해 과거 생성 원본과 시안은 모두 기록으로 보존합니다.
상하·대각선은 기존 걷기 시트를 사용하고, 좌우는 FourPhaseWalk-v9의 동작을 유지하고 v14에서 다리를 붙이고 v15에서 팔의 닫힌 어깨 선만 열었습니다.
위쪽 대각선은 기존 사용자가 선택한 시트와 재생 방식을 유지합니다.
각 버전의 Review/Iterations는 검토 이력이며, 실행 리소스의 정본은 Sources/ChiikawaCompanion/Resources입니다.
같은 Project 경로의 내용이 바뀌면 이전 사본을 Versions/<SHA-256 앞 16자리>/에 먼저 보존합니다.
이미지 생성 프롬프트와 검토용 렌더러·검증 결과도 함께 보관했습니다.

FourPhaseWalk-v9: T포즈 기반 양발 24프레임 측면 걷기 시트와 좌우 미리보기입니다.
사용자 검토 승인 후 앱에 적용했습니다. 적용 검증은 AppliedFourPhaseWalk-v10에 기록합니다.
CaveHome-v11: 사용자 집·수면 레퍼런스, 생성 원본, 프롬프트, 수면 GIF 및 실제 Mac 앱 화면 검증을 보관합니다.

ClickQuotes-v12: 사용자가 지정한 클릭 명대사 10개와 적용 검증 기록입니다. 기존 이미지 리소스는 유지합니다.

VoiceClips-v13: 성우 공개 샘플의 짧은 대사 4개, 편집 구간·출처·음량 분석·재현 스크립트·실제 Mac 재생 검증을 보관합니다. 기존 이미지와 명대사 10개는 유지합니다.

JoinedWalkAndMixedDialogue-v14: 기존 native rig의 발 궤적과 타이밍을 보존한 연결부 수정, 모든 중간 시안·좌우 GIF·24프레임 시트와 검증 기록입니다.

JoinedArms-v15: v14의 모든 다리 픽셀을 유지하면서 팔의 어깨 연결선만 연 24프레임 시트, 좌우 GIF, native renderer와 보존 검증 기록입니다.

DailyActions-v16: 사용자 레퍼런스 4개, 내장 image_gen으로 만든 세 동작과 투명 배경 검토 시안, 프롬프트·프레임 등록 도구·GIF·실행 검증 기록입니다. 기존 팔·다리·8방향 걷기 리소스를 유지합니다.

ActivitySpots-v17: 기존 소품 그림체로 그린 책상·털뭉치·밥의 native artwork와 거리 반응 검증 기록입니다. 각 소품의 클릭 방문·개별 드래그·좌표 독립·반복 발동 방지와 실행 화면을 보관합니다. 기존 일상 동작과 걷기 이미지 리소스는 그대로 유지합니다.
