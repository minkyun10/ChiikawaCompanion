하치와레 사스마타 디자인 통일 v57
작성: 2026-10-23
적용: 앱 0.27.1 / build 56

요청
  치이카와의 사스마타와 동일한 디자인으로 만들고 분홍색 부분만 하늘색으로 표시한다.
  누락된 흰 디테일을 비교하여 복원한다.

반영
  바닥 아이템, 일반/변신 상태의 8방향 장착, 변신 상태 무기 동작과 공격에
  치이카와의 도형·외곽선·기울기·흰 돌기 5개·흰 손잡이 끝을 공유한다.
  장착 중에도 가로/세로 비율을 치이카와와 통일한다.
  치이카와는 기존 분홍색 0xE9A7BC, 하치와레는 기존 하늘색 0x7DA6BC를 사용한다.
  카메라·기타 및 캐릭터의 청색 머리/꼬리는 변경하지 않는다.
  v7 무기 들기 자세는 승인된 원본 몸/얼굴/팔다리/무기를 유지하고,
  해당 자세의 무기 위에 native 도형으로 흰 돌기와 손잡이 끝만 한 번 합성한다.
  원본 PNG와 다른 여섯 자세는 그대로다. 실행 중 매 프레임 재합성하지 않는다.
  하치와레/치이카와 일반 공격 12프레임에는 이미 흰 돌기와 손잡이 끝이 있으므로
  기존 공격 원화와 신체 크기 등록을 유지하고 표시 상태를 비교했다.
  괴물 공격/무기 동작의 atlas는 새 공통 무기로 빌드 시 다시 생성한다.
  이동 속도, 10배 변신, 지면 접점, 호버 판정, 수면, 소품 소유, 클릭 전용 음성 규칙은 유지한다.

자료
  References/: 수정 전 native 도형 코드, 기존 무기 들기/공격 PNG.
  Review/01-initial/: 최초 비교/장착/공격 검토.
  Review/: 최종 색상 비교, 8방향 장착, 일반/변신 공격과 무기 들기.
  Audit/: 빌드, 자동 검사, 실행 리소스 보존 및 시각 비교 결과.
  생성형 이미지 도구나 외부 API 없이 앱의 기존 native 도형을 공유했다.

최종 검수

  실행 이미지 234개 중 괴물 무기 동작/공격 atlas 2개만 변경하고 나머지 232개 hash 보존.
