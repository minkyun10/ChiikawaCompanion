괴물 하치와레 10배 확대 v56
작성: 2026-10-23
적용: 앱 0.27.0 / build 55

요청: 하치와레가 커질 때 현재 캐릭터의 10배 크기로 표시.
가로와 세로 각각 10배로 적용한다. 기본 actor 132×150pt → 완성 괴물 1320×1500pt.
10초 안에 5회 클릭, 30초 유지, 650ms 변신/자동 복귀는 기존 동작을 유지한다.
외형 opacity와 같은 연속 시각으로 1→10배, 10→1배를 전환한다.

좌표와 입력
  지면 접점은 ItemWorld의 기존 (66,30)pt를 기준으로 한다.
  표시 window는 이 접점을 고정한 채 확대하며, 논리적인 이동 footprint는 132×150pt를 유지한다.
  목적지·소품·집 입구·모니터 변경·초기 배치에는 footprint를 사용한다.
  드래그는 논리적 위치를 화면 안에 제한하며 표시 window는 그 위치에서 10배로 그린다.
  화면보다 큰 표시 영역은 경계 밖으로 이어지도록 허용한다.
  실제 window translation은 그대로 이동으로 기록하고, 확대/축소의 Native 좌표 반올림은 접점에 누적하지 않는다.
  보행 phase는 실제 지면 이동거리를 현재 표시 배율로 나누어 계산해 큰 발의 보폭과 대응한다.
  클릭·호버·아이템 handover는 실제 확대된 window와 그 안의 정규화된 silhouette를 사용한다.
  사스마타 overlay도 실제 표시 크기를 받아 같은 10배 신체 크기로 공격한다.
  집 안 수면은 기존 고정된 공용 집의 침상 안에 표시하며, 집 자체의 크기와 위치는 유지한다.

자료
  새 이미지를 생성하지 않았다. 실행 PNG 및 v53/v55 원화·atlas·참고 이미지를 그대로 재사용한다.
  CharacterScale.swift: 표시 크기와 이동 좌표 분리 구현의 사본.
  Audit/: native frame 크기·지면 접점·rounding·hover·공격·걷기·자동 복귀 및 전체 회귀 검사.
  앱은 추가 시트나 시간에 비례하는 cache를 만들지 않는다. 확대된 window backing store는 일반 크기보다 커진다.

최종 검수
  완성 app bundle 전체 949개, 변신/확대 전용 65개 통과.
  실제 Native panel/frame 및 view bounds가 완성 시 1320×1500pt임을 확인했다.
  기존 실행 이미지 234개는 모두 hash가 같고 추가·삭제한 실행 이미지는 없다.
  중간 축소 요청 726×825pt는 AppKit에서 727×826pt로 올림됐다. 지면 접점은 동일하며 검사에서 native 1pt 반올림을 허용했다.
  기존 30초 복귀·독립 소품 좌표·음성 규칙·랏코 검과 다른 캐릭터 전체 기능을 회귀 검사했다.
  새 앱 실행·소환 8명 유지·설정 창 닫기를 CUA로 확인했다.
  별도의 실제 포인터 5회 클릭 육안 확인을 수행했다고 기록하지 않는다.
