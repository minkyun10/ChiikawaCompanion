치이카와의 하루 — v26 / 앱 0.15.0 (build 28)
작성일: 2026-10-20

v25에서 확인한 상징 소품·집·한국 성우·공개 연기 샘플을 개인용 Mac 앱에 적용했습니다.

적용
- 동굴 옆, Dock 위의 둥근 치이카와 집. 일반 앱 창 뒤, 바탕화면 아이콘 앞에 표시합니다.
- 집 클릭 → 바닥 열쇠를 챙김 → 집까지 걸어감 → 잠옷 입장 → 이불 수면 → 20초 후 기상.
  열쇠가 없거나 숨겨졌으면 바로 귀가합니다. 이동 중 열쇠를 건네도 귀가를 이어갑니다.
- 집 클릭으로 기상, 캐릭터 드래그로 귀가 취소, 집 숨김 시 먼저 기상.
- 치이카와 전용 분홍 책상. 클릭해 방문하거나 34pt 안에 들어오면 공부합니다.
  공부 12프레임은 1.8초 주기, 9초 재생입니다. 84pt 이탈과 30초 대기로 중복 발동을 막습니다.
- 분홍 잠옷과 갈색 인형 안기 자세는 각각 5초간 미세한 호흡 움직임을 보여 줍니다.
  인형을 주워도 즉시 안아 줍니다. 일상 동작 중 소품 그림만 가리고 착용 상태는 유지합니다.
- 기존 웃음·울음에 놀람·용기·수줍은 기쁨의 표정 3개를 추가했습니다.
- 실제 한국 성우 이주은의 공개 치이카와 연기에서 짧은 반응 4개를 잘라 로컬 재생합니다.
  직전 반응은 연속 선택하지 않습니다. 두 친구의 재생·중단·음소거 설정은 독립적입니다.
- 집·책상·바닥 소품은 각각 화면 좌표를 가지며 캐릭터 이동에 따라 움직이지 않습니다.
- 설정, 캐릭터 우클릭, 메뉴 막대의 치이카와 메뉴에서 새 동작을 선택할 수 있습니다.

보존
- 기존 실행 리소스 32개의 SHA-256을 모두 보존했습니다.
- 치이카와 8방향 24프레임 걷기와 무기 공격, 하치와레 그림·녹음·일상·동굴 동작은 유지합니다.
- 하치와레의 가방과 카톡 연동은 다시 추가하지 않았습니다.

이미지
- 내장 image_gen으로 집, 공부 시트, 수면·잠옷·인형·표정 시트의 원본 3장을 생성했습니다.
- Generated/에 모든 원본, Prompts/에 실제 프롬프트를 보관합니다.
- References/에 기존 기준 시트와 SEGA 공식 집·소품 자료 사본을 보관합니다.
- generations.json은 출처·원래 파일 이름·해시를 기록합니다.
- PrepareStudyAtlas.swift는 12프레임의 머리 크기·발 기준선을 등록합니다.
- PrepareLifeAssets.swift는 실제 투명 여백을 찾아 원본 그림의 포즈를 분리합니다.
- Final/은 실행 리소스와 동일한 등록본이며 원본의 alpha를 유지합니다.
- Review/chiikawa-life-v26.png, chiikawa-study-v26.gif에서 렌더를 확인할 수 있습니다.

음성
- 공개 원본: https://www.youtube.com/watch?v=V0IPf4ENMJs
- 성우 채널: https://www.youtube.com/@jooeun_2
- Audio/Originals/에 실제 내려받은 37.801초 webm 원본을 보관합니다.
- Audio/Clips/는 1.56 / 2.32 / 1.92 / 1.78초의 짧은 원본 반응입니다.
- 음성 합성·복제는 하지 않았으며 계정 쿠키·개인 credential·API key를 사용하지 않았습니다.
- 감정별 파일 이름은 앱에서의 연기 배치입니다. 원본 장면 이름이나 검증된 대사 전사가 아닙니다.
- 말풍선은 감정 표시입니다. 원본이 비언어적 소리 위주여서 문장 전사를 만들어 넣지 않았습니다.
- 자동 전사 결과는 transcript-machine.json에 미검증 기계 출력으로 보관합니다.
  외국어처럼 잘못 인식한 부분과 마지막 채널 안내를 대사로 사용하지 않았습니다.
- 원본의 배경음은 별도 분리하지 않았습니다. 고역 통과·음량 정규화·짧은 fade만 적용했습니다.
- 편집 시각·출처·해시·길이·음량은 Audio/catalog.json, provenance.json, validation.json에 있습니다.
- 다시 제작: python3 Source/ChiikawaLife-v26/Audio/prepare-clips.py

검증
- self-test-cli.txt: 실제 controller를 이용한 귀가·열쇠 전달·입장·수면·기상·공부·인형·음성 검증.
- asset-verification.json: 이전 리소스 32개 보존, 새 alpha 이미지 8개, 공부 cell 12개, 녹음 4개 일치.
- build-log.txt: release 빌드, 앱 패키징, ad-hoc 코드 서명 기록.
- 실제 Mac 화면 점검은 잠금 해제 후 진행하며 validation.json에 최종 상태를 기록합니다.

공식 자료의 근거 링크와 확인 범위는 ../ChiikawaResearch-v25/sources.json을 함께 봅니다.
개인 프로젝트용 적용 기록이며 공개 음원 재사용에 관한 권리 허락을 나타내지 않습니다.
