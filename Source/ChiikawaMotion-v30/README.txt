치이카와 생활 연속 모션 — 앱 0.17.0 (build 32)

적용
- 식사 12프레임: 밥 집기 → 입으로 가져가기 → 씹기 → 젓가락 내리기. 1.8초 주기로 6초 재생.
- 치이카와 전용 밥그릇: 별도 화면 좌표, 클릭 방문, 드래그 이동, 거리 반응을 지원합니다.
  34pt 진입, 84pt 이탈, 30초 재반응 대기를 기존 책상과 공유합니다.
  동작 중에는 그림에 포함된 그릇만 숨기고 종료 시 같은 위치에 복원합니다.
  자동 행동을 꺼도 직접 방문 요청은 동작합니다. 그릇을 숨기면 방문/식사를 취소합니다.
- 인형 안기 12프레임: 들어 올리기 → 가슴으로 당기기 → 꼭 안기 → 살짝 풀기.
  첫 6프레임의 접근 후 뒤 6프레임을 부드럽게 반복하며 5초 후 산책합니다.
- 잠옷 12프레임: 옷 끌어올리기 → 팔 넣기 → 후드 쓰기 → 옷매무새 정리.
  처음 1.8초 동안 옷을 입고 마지막 자세를 유지하며 총 5초 후 산책합니다.
- 수면/기상 16프레임: 앞 8개는 하품·눕기·이불 덮기·눈 감기, 뒤 8개는 눈뜨기·이불 걷기·기지개입니다.
  잠든 후 20초에 자동 기상하고 0.96초의 기상 모션을 집 안에서 끝낸 다음 산책합니다.
  다른 동작 선택·친구 부르기·숨김은 해당 전환을 취소하며 다른 친구의 수면은 유지합니다.
- 눈 깜박임 6프레임: 정면의 눈 두 영역만 기존 걷기 위에 합성합니다.
  약 4.8초마다 0.27초 동안 깜박이며 기존 몸·귀·팔·다리 픽셀과 걷기 위상은 유지합니다.
  옆/뒷면과 고유 표정·생활 동작에는 정면 눈을 얹지 않습니다.
- 표정 5개 사이를 0.1초 동안 이전/다음 그림으로 전환합니다.
  투명 layer 안에서 합성해 몸통이 반투명해지는 현상을 피합니다.
- 치이카와 토하기는 추가하지 않았습니다. 하치와레의 기존 생활 동작은 유지합니다.
- 공용 집 한 채·기본 하치와레·치이카와의 복원된 둥근 집 디자인·고정 위치는 유지합니다.

제작과 보관
- 내장 image_gen으로 원본 5장을 만들었습니다. 외부 API key나 credential은 사용하지 않았습니다.
- Generated/: 모든 원본 RGBA PNG. 채택 전 원본을 덮어쓰거나 삭제하지 않았습니다.
- Prompts/: 각 도구 호출에 사용한 전체 프롬프트. References/: 기존 기준 그림 사본.
- generations.json: 원본 출처 경로·도구·해시와 프롬프트 연결.
- PrepareMotionAtlas.swift: 투명 gutter를 찾아 분리하고 256 × 256 cell에 등록합니다.
  식사·인형·잠옷·눈은 흰 본체를 기준으로, 수면/기상은 한 주기의 공통 scale로 등록합니다.
  배경 교체나 새 픽셀을 그리는 방식 없이 생성된 alpha와 그림 픽셀을 보존합니다.
- Final/: 58개 개별 프레임, 등록 metadata와 실행 atlas 5장.
- Review/: 각 atlas와 GIF, 실제 걷기의 눈 합성, 표정 전환, 공용 집 수면 검토 자료.
  blink-v30.gif는 눈꺼풀 원화의 자세 검토용이며 walking-blink-v30.gif가 실제 걷기 합성 주기입니다.
- 기존 실행 이미지·녹음 46개는 모두 93f89d8과 byte 단위로 같습니다.
