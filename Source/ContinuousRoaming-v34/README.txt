자동 산책의 좌표 점프 수정 — 2026-10-21

사용자 보고: 아무것도 누르지 않고 걷는 도중 순간이동함.
버전 0.17.4, build 36.

재현
regression-before.log에서 실제 controller를 60Hz로 진행했습니다.
생활 소품 28pt 앞에서 시작하면 하치와레 책상·밥·털뭉치와 치이카와 책상·밥 모두
한 tick에 28pt를 이동하고 동작을 시작했습니다.
사용자 화면에서 발생한 개별 사건의 원인을 로그로 추적한 것은 아니며, 같은 증상을 만드는 자동 경로의 재현입니다.

변경
- 34pt는 소품을 발견해 접근을 시작하는 거리로 유지합니다.
- 2pt 이내까지 실제 걸어온 뒤 행동합니다. 도착한 현재 위치에서 동작을 시작하며 좌표를 강제로 정렬하지 않습니다.
- 생활 소품 경로의 정지 거리는 0.5pt로 낮추고 일반 산책의 5pt 도착 기준·속도는 유지합니다.
- 산책이 꺼져 있으면 자동 접근으로 켜지지 않습니다. 직접 소품 방문은 기존처럼 산책을 켭니다.
- 화면 구성 알림에서 시작 위치로 초기화하지 않습니다. 화면 안의 좌표·행동은 유지합니다.
- 사라진 화면 등에 남은 캐릭터는 이동 거리가 가장 작은 유효 화면 안으로만 복구합니다.
- 실제 창 위치와 소수점 누적 좌표가 2pt 넘게 달라지면 실제 창을 기준으로 이동을 다시 시작합니다.
  일반/Retina 창 반올림의 소수점 누적은 유지합니다.
- 시작 위치 배치는 앱 시작과 명시적 부르기에 유지합니다.
- 집·소품 좌표, 동작 그림, 공격, 클릭 전용 음성과 설정은 유지합니다.

데이터
위치 이력·로그·녹음·스크린샷의 상시 저장은 추가하지 않았습니다.
설정만 UserDefaults에 저장하고 위치·장착·행동은 여전히 실행 메모리에 있습니다.
그림을 시작 시 메모리에 올려 재사용하며 음성 재생 완료 시 플레이어를 해제합니다.
macOS Metal 캐시는 시스템이 관리하며 Source/.build는 제작·빌드 때만 갱신하는 자료입니다.

검증
양 캐릭터의 다섯 자동 동작에서 모든 이동 tick과 최종 도착을 검사합니다.
반복 화면 구성 알림의 위치·동작 보존, 외부 창 이동 후 재개를 검사합니다.
검사 결과·기존 리소스 보존·서명·재실행은 validation.json 및 로그를 참고합니다.

Mac 창 반올림 검사에서 정확한 앵커를 요청해도 실제 창/앵커가 1.032pt 어긋날 수 있음을 확인했습니다. 도착 허용치는 2pt이며 도착 후 강제 좌표 정렬은 제거했습니다. 표준/Retina의 내림·최근접 반올림으로 모든 접근 각도를 검사합니다.
